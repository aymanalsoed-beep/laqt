الدخول إلى اللوحة

اللوحة تحفظ ما تكتبه في مستودع الموقع على GitHub مباشرة، ثم يُنشر الموقع بنفسه خلال دقيقتين تقريبًا. لذلك تحتاج مرة واحدة إلى «مفتاح دخول» من حسابك في GitHub.

طريقة إنشاء المفتاح (مرة واحدة)
  1. افتح صفحة إنشاء مفتاح جديد في GitHub وأنت داخل حسابك.
  2. في Token name اكتب: لوحة لقط. وفي Expiration اختر المدة التي تريد (سنة مثلًا).
  3. في Repository access اختر Only select repositories ثم اختر المستودع laqt وحده.
  4. في Permissions افتح Repository permissions واجعل Contents على Read and write، وActions على Read-only (ليظهر لك تقدم النشر).
  5. اضغط Generate token في الأسفل، ثم انسخ المفتاح الذي يبدأ بـ github_pat_ والصقه هنا.

المفتاح يبقى في متصفحك وحده، ولا يصل إلا إلى GitHub. ولا يفتح إلا هذا المستودع. وإن فقدت الجهاز فاحذفه من الصفحة نفسها في GitHub.
