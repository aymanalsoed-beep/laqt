# لقط

موقع لفوائد القرآن الكريم: المصحف كاملًا برواية حفص عن عاصم، وتحت كل آية تبويبات للفوائد والتفسير والإعراب. الآية التي لم تُكتب لها مادة بعد تظهر بخانات فارغة تنتظر ما يُنشر فيها.

## المراحل

1. **قاعدة البيانات**: نص المصحف، والسور، والأجزاء والأحزاب والأرباع، والفوائد الأولى مربوطة بآياتها.
2. **واجهة الموقع** بحسب هوية «لقط» (انظر «الموقع» أدناه).
3. لوحة إدخال الفوائد والتفسير والإعراب.
4. مصادر التفسير والإعراب.

## المحتويات

| المسار | ما فيه |
| --- | --- |
| `db/schema.sql` | مخطط قاعدة البيانات، مشروح بالعربية |
| `db/laqt.db` | قاعدة البيانات مبنية (SQLite) |
| `scripts/build_db.py` | يبني القاعدة من المصادر ويتحقق منها |
| `data/sources/kfgqpc/` | نص المصحف من مجمع الملك فهد، كما نُشر دون تعديل |
| `data/sources/quran-meta/` | قوائم السور وبدايات الأرباع والسجدات والمنازل |
| `data/fawaid/initial_fawaid.json` | ملف «برمجة لقط الأولية»: 103 فوائد |
| `data/fawaid/link_report.md` | تقرير التحقق من ربط الفوائد بآياتها |
| `scripts/build_site.py` | يولّد الموقع الثابت من القاعدة إلى `_site/` |
| `scripts/site_config.json` | إعدادات الموقع: الحالات المنشورة، والخانات المخفية، والقارئ |
| `site-src/assets/` | التنسيق والسلوك وخط المصحف |
| `.github/workflows/pages.yml` | ينشر الموقع على GitHub Pages عند كل دفع إلى main |

بناء القاعدة من جديد (Python 3 فقط، بلا مكتبات إضافية):

```sh
python3 scripts/build_db.py
```

## الموقع

موقع ثابت يُولَّد من القاعدة (Python 3 فقط، بلا مكتبات):

```sh
python3 scripts/build_site.py          # يكتب الموقع في _site/
python3 -m http.server -d _site 8000   # معاينة على http://localhost:8000
```

- **الرئيسية**: الشعار والبحث وفهرس السور الـ114، مع عدد الفوائد في كل سورة وتصفية بالاسم.
- **صفحة السورة**: كل آياتها برسم المجمع، وتحت كل آية الخانات الخمس بالترتيب المعتمد: القراءات، المعنى الإجمالي، التفسير بالمأثور، الإعراب، الفوائد. الخانة التي فيها مادة تحمل عددها، وخانة الفوائد تُفتح تلقائيًا، والخانة الفارغة تظهر هادئة وتقول إن مادتها لم تُنشر بعد. فوائد مقدمة السورة قبل أول آية، وفوائد ختامها بعد آخر آية، والفائدة المستشهَد فيها بآية تظهر تحتها مع رابط موضعها الأصلي.
- **أدوات القارئ**: الاستماع للآية أو للسورة متتابعة (الحصري)، والانتقال إلى آية، وتكبير الخط، وإخفاء الخانات الفارغة، ونسخ رابط الآية.
- **الفوائد**: فهرس مرتب بمواضعها، وصفحة مستقلة لكل فائدة للنشر والمشاركة. الإحالات مثل «[البقرة: ٦١]» تصير روابط، والآيات بين ﴿ ﴾ تُعرض بخط المصحف.
- **البحث**: في نص الآيات بلا تشكيل وفي الفوائد، و«البقرة ٢٥٥» تفتح الآية مباشرة.
- **الإعراب** مخفي في الإعدادات (`hidden_kinds`) حتى يُتحقق من حقوق «التفصيل»؛ حذفه من القائمة يُظهره للجميع.
- لا يظهر من المواد إلا ما حالته في `public_statuses` (الآن: `ready` و`published`).

**النشر**: من إعدادات المستودع ← Pages ← Source: GitHub Actions. بعدها يُبنى الموقع ويُنشر تلقائيًا عند كل دفع إلى main.

## البنية باختصار

- `surahs`: 114 سورة، مع عدد الآيات ومكية/مدنية وترتيب النزول وصفحة البداية والنهاية.
- `ayat`: 6236 آية، لكل آية: الرسم العثماني، والرسم الإملائي للبحث، والصفحة والسطر في مصحف المدينة، والجزء والحزب والربع والمنزل والسجدة.
- `rubs`: أرباع الأحزاب الـ240 وأول آية وآخر آية في كل ربع.
- `content_kinds`: الخانات الخمس تحت كل آية (القراءات، المعنى الإجمالي، التفسير بالمأثور، الإعراب، الفوائد)، ويضاف إليها ما يُستجد دون تغيير البنية.
- `entries`: كل مادة (فائدة أو تفسير أو إعراب أو غيرها) بنصها ومصدرها وحالتها (`draft`، `needs_review`، `ready`، `published`).
- `entry_ayat`: ربط المادة بآية أو مقطع، ويجوز أن ترتبط المادة بأكثر من موضع، مع موضع العرض (تحت الآية، أو مقدمة السورة، أو آخرها). وحقل `role` يميّز الموضع الأصلي للفائدة (`primary`) من الآيات التي تستشهد بها (`cited`)، فتظهر الفائدة تحت كلٍّ منها.
- `sources`: الكتب المنقول عنها، تُعبأ في المرحلة الرابعة.
- العرض `ayah_overview`: كل آية مع عدد موادها في كل تبويب؛ الأصفار هي الخانات الفارغة.

## ملاحظات على الأجزاء والأرباع

- بدايات الأرباع مأخوذة من علامات ۞ في نص المجمع نفسه، فهي مطابقة لمصحف المدينة. وتختلف عن قوائم quran-meta في موضع واحد: ربع ﴿نَبِّئۡ عِبَادِيٓ﴾ يبدأ عند الحجر 49 لا 50.
- في المصحف المطبوع قد تبدأ صفحة الجزء قبل علامته بآية (مثل ﴿لَن تَنَالُواْ ٱلۡبِرَّ﴾ في أعلى صفحة الجزء الرابع، وعلامة الجزء عند ﴿كُلُّ ٱلطَّعَامِ﴾). لذلك في الجدول حقلان: `juz` بحسب العلامة، و`page_juz` بحسب ما يُطبع أعلى الصفحة.

## المصادر والتراخيص

- **نص القرآن**: [مجمع الملك فهد لطباعة المصحف الشريف](https://qurancomplex.gov.sa/techquran/dev/)، بيانات حفص للمطورين الإصدار 18، عبر النسخة المنشورة في [thetruetruth/quran-data-kfgqpc](https://github.com/thetruetruth/quran-data-kfgqpc). الملف محفوظ كما نُشر دون تعديل، وحقل `text_uthmani` لا يزيد على حذف رقم الآية وعلامة ۞ للعرض. يُعرض النص بخط «حفص» الصادر من المجمع (الإصدار 18) ليظهر الرسم صحيحًا. ويتيح المجمع استعمال نسخته الرقمية مجانًا في المواقع والبرامج ([شروط الاستخدام، نسخة مؤرشفة](https://web.archive.org/web/20250123095851/https://dm.qurancomplex.gov.sa/rights/)).
- **القوائم الوصفية**: [quran-meta](https://github.com/quran-center/quran-meta) الإصدار 7.0.0، برخصة MIT (`data/sources/quran-meta/LICENSE`).
